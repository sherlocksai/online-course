Eight modules. One working application.

Module 01

Foundations of Web Development

Start with the building blocks: accessible markup and CSS layout systems, applied to a real, responsive site rather than isolated exercises.

  • Semantic HTML and accessible page structure
  • Responsive layout with Flexbox and CSS Grid
  • A reusable styling system with custom properties
  • Build: a responsive, multi-page personal site

Module 02

Java Programming Fundamentals

A proper grounding in Java — not just syntax, but the object-oriented thinking that Spring Boot and the rest of the backend modules build on.

  • Core syntax, control flow and object-oriented design
  • Collections, generics and working with data in memory
  • Exception handling and defensive coding habits
  • Build: a command-line inventory management tool

BeginnerLevel

Module 03

Databases & Backend Systems

Model real data, expose it through a proper API, and understand what's actually happening between a request and a database row.

  • Relational modeling and SQL fundamentals
  • Building REST controllers with Spring Boot
  • Persistence with JPA and Hibernate
  • Build: a REST API backed by a MySQL database

Module 04

UX/UI Design Principles

A short, practical detour into design — enough to make deliberate layout and usability decisions in your own project instead of guessing.

  • Visual hierarchy and layout grids
  • Wireframing and low-fidelity prototyping
  • Core usability heuristics
  • Build: wireframes and a high-fidelity mockup for your capstone

Cloud Deployment & DevOps Basics

The gap between "runs on my machine" and "runs for anyone" — closed with a working deployment pipeline, not just a slide about one.

  • Environments, secrets and config management
  • Containerizing your application with Docker
  • Deploying to a cloud platform
  • Build: deploy your backend to a live environment
